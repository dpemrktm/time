이번 분기 전체 현황

🎯 이번 분기 One Thing

이번 분기 단 하나만 한다면 무엇? (ISTJ 분석 무한루프 방지장치)

1. GitHub 분기 누적 커밋 수
본인 GitHub 잔디 페이지에서 이번 분기 커밋 수를 세어 입력. 규모 무관, 푸시했다는 사실이 KPI.
🟢 양호 65회 이상 (주 5회+)
🟡 주의 26~64회 (주 2~4회)
🔴 경고 25회 이하 → 다음 주 일요일 1시간 강제 코딩 블록
2. 기술 블로그 분기 발행 편수
velog, medium, 티스토리 등에 발행한 글 수. 글 길이 무관 (800자도 1편).
🟢 양호 3편 이상
🟡 주의 1~2편
🔴 경고 0편 → 다음 분기 첫 글은 "왜 못 썼는가" 회고로
3. LinkedIn 프로필 조회 수 (월 평균)
LinkedIn에서 본인 프로필을 누가 봤는지 통계. 분기 3개월 평균.
🟢 양호 월 30회 이상
🟡 주의 10~29회
🔴 경고 10회 미만 → 이력서 키워드 재정비
4. 헤드헌터 분기 인콜 건수
헤드헌터·리크루터가 먼저 연락해온 횟수 (이메일·DM·전화). 본인 시장가치의 가장 신뢰할 만한 외부 신호.
🟢 양호 3건 이상
🟡 주의 1~2건
🔴 경고 0건 → 채용공고 5개와 본인 프로필 매칭률 점검
5. 본업 정량 성과 (숫자로 말할 수 있는 것)
"자동화로 ○시간 단축", "결함 ○건 사전 발견" 같이 숫자로 표현 가능한 성과 수. 다음 이력서·면접의 원료.
🟢 양호 2개 이상
🟡 주의 1개
🔴 경고 0개 → 2분기 연속이면 본업 정체 신호
6. 이번 분기 스킬 마일스톤
이번 분기에 새로 익숙해진 기술 1가지를 명시. (비어 있으면 다음 분기 학습 범위를 1가지로 좁히세요.)
1. 월 저축률 (%)
(저축 + 투자 입금 + 부채 원금 상환) ÷ 월 세후 소득 × 100
🟢 양호 25% 이상
🟡 주의 15~24%
🔴 경고 15% 미만 → 고정비 5개 카테고리 5%씩 감축
2. 금융자산 비중 (%)
(예적금+ETF+주식+연금+IRP+채권) ÷ 총자산 × 100. 한국 50대의 75.8%가 부동산에 묶여 노후 빈곤율을 만듭니다. 40대에 전환 시작.
🟢 양호 전 분기 대비 +1%p 이상 (우상향)
🟡 주의 횡보 (±1%p 이내)
🔴 경고 우하향 → 월 자동이체 +10만원 증액
🎯 5년 목표: 30% 이상
3. 비상자금 활주로 (개월)
즉시 인출 가능한 현금성 자산 ÷ 월 고정지출. 본업 결정의 품질을 좌우.
🟢 양호 6개월 이상
🟡 주의 3~5개월
🔴 경고 3개월 미만 → 변동 지출 50% 감축
4. 부가 수입 누적 (만원)
본업 외 발생 수입의 분기 누적액. 강의·외주·블로그 광고·이자·배당 등.
🟢 양호 분기별 단계 목표 달성 (1년차: 1만원+, 2년차: 100만원+)
🟡 주의 채널은 있으나 수입 미발생
🔴 경고 Year 2까지 누적 0원 → 채널 1개로 좁혀 6개월 집중
5. 연금저축·IRP 한도 활용률 (%)
(연금저축+IRP 납입액) ÷ 900만원 × 100. 세제혜택 13.2~16.5% = 확실한 수익률.
🟢 양호 80% 이상
🟡 주의 40~79%
🔴 경고 40% 미만 → 12월까지 추가 납입 검토
1. 주 평균 운동 횟수
30분 이상 활동 (걷기·달리기·자전거·홈트 무관) 횟수의 분기 평균.
🟢 양호 주 3회 이상
🟡 주의 주 1~2회
🔴 경고 주 0회 → 다음 주 운동 블록 캘린더 사전 등록
2. 주 평균 수면 시간
취침-기상 시각으로 측정한 분기 평균.
🟢 양호 6.5~7.5시간
🟡 주의 5.5~6.4 또는 7.6~8.5
🔴 경고 5.5시간 미만 → 어떤 학습도 수면 깎지 말 것
3. 체중 (kg)
매월 1일 아침 공복 측정. 분기 평균값.
4. 혈압 (수축기 / 이완기)
가정 혈압계로 측정. 분기 평균.
🟢 양호 120/80 이하
🟡 주의 121~139 / 81~89
🔴 경고 140/90 이상 → 한 달 내 진료 예약
5. 올해 종합검진 완료?
연 1회. 매년 4월 안에 완료 권장.
1. 아들과 1:1 시간 (주 평균)
아내 없이 아들과 둘만 보낸 시간 (식사·놀이·대화). 초4~고1 사이 약 400주가 남았습니다.
🟢 양호 주 3시간 이상
🟡 주의 주 1~2시간
🔴 경고 주 1시간 미만 → 다음 주 아빠-아들 2시간 외출 예약
2. 부부 대화 시간 (주 평균)
아이가 없는 자리에서 부부 함께한 시간. TV 같이 보기는 50%만 인정.
🟢 양호 주 4시간 이상
🟡 주의 주 2~3시간
🔴 경고 주 2시간 미만 → 주 1회 부부 산책 30분 반복 등록
3. 가족 외출 (월 평균)
셋이 함께 집 밖에서 보낸 일정 (외식·여행·나들이).
🟢 양호 월 2회 이상
🟡 주의 월 1회
🔴 경고 월 0회 → 매월 2·4주 일요일 반복 등록
4. 가족 시간 학습·일 침범 횟수 (주 평균)
⚠️ 이건 낮을수록 좋습니다. 가족 활동 중 폰으로 일 처리한 횟수.
🟢 양호 주 0회
🟡 주의 주 1회
🔴 경고 주 2회 이상 → 다음 주 가족 시간 폰 다른 방에 두기
1. 시장가치 자가진단 (0~4점)
아래 4개 질문 중 즉답 가능한 개수:
① 내 적정 연봉 범위
② 그 근거 (헤드헌터·잡플래닛·면접 결과)
③ 부족한 스킬
④ 향후 12개월 학습 1순위
🟢 양호 4개 모두
🟡 주의 2~3개
🔴 경고 1개 이하 → 다음 분기 채용공고 5건 + 헤드헌터 통화
2. 분기 외부 출시·공개 건수
외부에 닿은 산출물 카운트 (블로그·GitHub 푸시·강의 슬라이드·이력서 업데이트·면접 응시 등). ISTJ 분석 함정에 대한 가장 강력한 카운터.
🟢 양호 20건 이상
🟡 주의 10~19건
🔴 경고 10건 미만 → 학습 50%↓ 출시 200%↑
3. 분기 회고 작성 완료?
분기말 1시간 회고. [📝 회고] 탭에서 작성.

📈 분기별 추이

지표 하나를 선택하면 모든 분기의 추이를 그래프로 볼 수 있습니다. 최소 2개 분기의 데이터가 있어야 의미가 있습니다.

🎯 카테고리별 점수 추이

5개 카테고리의 양호(🟢) 비율을 분기별로 비교합니다.

🚀 시작하기

  1. 각 탭(커리어/재정/건강/가족/자기인식)을 차례로 열어 수치를 입력합니다.
  2. 입력하면 자동으로 동그라미 색이 바뀝니다 (🟢양호 / 🟡주의 / 🔴경고).
  3. 우측 하단 [💾 저장] 버튼을 누르면 이 브라우저에 영구 저장됩니다.
  4. 분기말에는 [📝 회고] 탭에서 글을 작성합니다.

📅 측정 리듬

  • 매주 일요일 밤 15분: 이번 주 데이터 입력
  • 분기말(3·6·9·12월 마지막 주): 1시간 회고 작성
  • 연 1회: KPI 자체를 재설계

⚠️ 운영 주의사항

  • 모든 KPI를 한꺼번에 추적하지 마세요. 처음엔 커리어 + 가족 2개만, 익숙해지면 추가하세요.
  • 숫자가 안 따라온다고 자책하지 마세요. 측정의 목적은 비난이 아니라 다음 분기 의사결정의 재료입니다.
  • 3개월 후 임계값을 조정하세요. 처음 정한 기준이 너무 빡빡하거나 느슨할 수 있습니다.

💾 데이터 보관

  • 모든 데이터는 이 브라우저에 저장됩니다 (인터넷 연결 불필요).
  • 분기 데이터는 영구 보존되며 분기를 바꿔도 이전 데이터는 그대로 남습니다.
  • 다른 기기에서도 같은 클로드 계정으로 접속하면 데이터가 보입니다.

📥 CSV 내보내기

  • 상단의 [📥 CSV] 버튼을 누르면 모든 분기 데이터를 엑셀 파일로 다운로드합니다.
  • 한글이 깨지지 않게 처리되어 있어 엑셀에서 바로 열립니다.
  • 백업이나 다른 도구로 옮길 때 활용하세요.

📈 분기 비교 차트

  • [📈 분기 비교] 탭에서 지표 하나를 선택하면 분기별 추이를 그래프로 볼 수 있습니다.
  • 최소 2개 분기 데이터가 있어야 추세가 보입니다.
  • 아래쪽 카테고리 차트는 5개 영역(커리어·재정·건강·가족·자기인식)의 양호 비율을 한꺼번에 비교합니다.
  • 색이 우상향이면 잘 가고 있는 것, 우하향이면 점검 필요 신호.

🎯 분기말 회고 템플릿

  • 다음 분기 One Thing (단 하나의 목표)
